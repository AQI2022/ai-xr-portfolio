# RAG 检索评测

本文是作品集自编测试资料。

RAG 链路包含文档解析、分块、Embedding、索引、检索、重排、生成与引用返回。Chunk size 较小有利于精确定位，但可能丢失上下文；overlap 能保留跨块语义，也增加重复与索引成本。

检索端使用 Recall@K、MRR 和来源覆盖率。生成端检查答案正确性、忠实度、引用是否支持断言以及无证据时是否拒答。仅验证引用 ID 存在，不能证明答案受到来源支持。

Hybrid search 将关键词检索与向量检索结合；RRF 按排序融合两路结果，减少原始分数尺度差异。Reranker 对候选片段和问题重新打分，通常提高相关性但带来额外时延。
