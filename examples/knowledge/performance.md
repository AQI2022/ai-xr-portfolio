# Unity 性能排查

本文是作品集自编测试资料。

Unity 应用出现卡顿时，先用 Profiler 判断主要瓶颈在 CPU、GPU、内存分配还是资源加载。脚本每帧产生临时对象可能增加 GC 压力；可复用集合、对象池，并避免在 Update 中频繁查找对象。

Draw Call、透明物体过绘、材质数量和网格复杂度会影响渲染成本。不要只凭 FPS 推断瓶颈，应同时记录目标设备、分辨率、测试场景、帧时间和测量方法。

LLM 或网络请求不应阻塞 Unity 主线程。UnityWebRequest 可通过协程等待结果，显示加载状态、超时提示及重试按钮。收到响应后再在主线程更新 UI 和场景对象。
